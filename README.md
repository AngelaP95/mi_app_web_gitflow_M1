# Mi App Web GitFlow M1

Aplicación web básica desarrollada para practicar GitFlow, control de versiones y despliegue de un proyecto sencillo con HTML, CSS y JavaScript.

## Descripción

Este proyecto incluye una página web simple con:

- un botón interactivo
- un formulario para ingresar nombre y correo
- diseño básico con CSS
- lógica de JavaScript para mostrar mensajes en pantalla

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Git
- GitFlow

## Estructura del proyecto

```text
mi_app_web_gitflow_M1/
├── index.html
├── styles.css
├── app.js
├── README.md
└── .git/
```

## Cómo ejecutar el proyecto

1. Clona el repositorio.
2. Abre la carpeta del proyecto.
3. Ejecuta el archivo `index.html` en tu navegador.

También puedes usar un servidor local si prefieres:

```bash
python -m http.server 8000
```

Luego abre en el navegador:

```text
http://localhost:8000
```

## Funcionalidades

- Botón que cambia el texto al hacer clic.
- Formulario que captura datos del usuario.
- Interacción básica con el DOM usando JavaScript.

## GitFlow

Este proyecto se trabaja con flujo de ramas tipo GitFlow, por ejemplo:

- `main` para producción
- `develop` para integración
- `feature/*` para nuevas funcionalidades
- `hotfix/*` para correcciones rápidas
